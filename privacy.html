Mony – Privacy policy

Last updated: November 6, 2026

Mony is a private assistant run by one household for its own members only.

Google user data

  • Mony requests only the gmail.readonly scope. It reads messages to find receipts, invoices and bills. It never sends, deletes, modifies or labels email.
  • Extracted details (merchant, date, amount) are stored on the household's own private server and used only to answer that household's questions about its finances.
  • Data is not sold, shared with or transferred to third parties, and is not used for advertising. Message content is processed by an AI model (Anthropic API) solely to extract receipt details; it is not used to train models.
  • Mony's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Data is kept only while the household uses Mony. Access can be revoked at any time at myaccount.google.com/permissions; on request, stored data is deleted.
